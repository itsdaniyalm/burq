## 1. What Is burq

**burq** (بُرق, Arabic/Urdu for "lightning") is a Python UI compiler. You write Python component code; `burq build` compiles it to pure Vanilla JS + HTML + CSS. No JavaScript knowledge required. No framework. No runtime server.

- **Taglines**: "Write Python. Ship UI." / "No JS. No apologies."
- **Name rule**: always lowercase `burq` — never Burq, BURQ, BurQ
- **PyPI**: `pip install burq`
- **GitHub**: https://github.com/itsdaniyalm/burq
- **Docs site**: https://burq.dev
- **Author**: Daniyal

## 2. Core Architecture

```
FastAPI  →  routing, auth, data APIs, serving dist/
Burq     →  compile app.py → dist/ (templates + JS + CSS)
Browser  →  JS reads URL params, fetches data from your API
```

**Pipeline (5 steps)**:
1. **PARSE** — load `app.py`, execute decorators, populate `app._pages`
2. **GENERATE HTML** — each `@app.page` → one Jinja2 template; components → HTML via `render_node()`; dynamic routes → inline JS param extraction
3. **GENERATE JS** — `burq.js` runtime (fetch wrapper, table hydration, sidebar, theme toggle, modals, toasts, tabs, dropdowns, accordions, file uploads)
4. **GENERATE CSS** — `tokens.css` (CSS custom props from Theme), `layout.css` (grid/topbar/sidebar/nav), `components.css` (all component styles)
5. **OUTPUT** — `dist/templates/` + `dist/static/`

**Key principle**: Burq is a compiler, not a framework. FastAPI owns routing. Burq owns compilation. No file copying — all CSS is generated by `css_gen.py`.

## 4. Design System — Filament Theme

**Canonical theme is Filament. These are the authoritative values.**

### Dark Mode
| Token | Value |
|---|---|
| `background` | `#0a0a0b` |
| `surface` | `#111113` |
| `surface_raised` | `#1e1e22` |
| `muted` | `#1e1e22` |
| `muted_fg` | `#8a8a93` |
| `accent` | `#F08C1A` |
| `accent_fg` | `#0a0a0b` |
| `border` | `#2a2a2e` |
| `chrome` | `#111113` |
| `chrome_fg` | `#8a8a93` |
| `success` | `#2ec97a` |
| `error` | `#e05252` |

### Light Mode
| Token | Value |
|---|---|
| `background` | `#fef9ed` |
| `surface` | `#fff` |
| `muted` | `#f5ecd6` |
| `muted_fg` | `#5c4d2e` |
| `accent` | `#F08C1A` |
| `border` | `#ebe0c2` |

### Chart Colors (default order)
```python
["#F08C1A", "#60a5fa", "#2ec97a", "#e05252", "#c97a2e", "#a78bfa", "#f472b6"]
```
These compile to `--chart-colors` CSS variable.

> **NOTE**: Prussian blue (`#0E1428`) is for the docs/marketing site ONLY — not the app theme.

### Typography
| Role | Font | Weight |
|---|---|---|
| Display / UI | Space Grotesk | 700 |
| Body / Labels | Space Grotesk | 400, 500 |
| Code / CLI / Mono | Space Mono | 400 |

### Spacing
Base unit: 4px (`--space-1`). Scale: `--space-2`=8px, `--space-3`=12px, `--space-4`=16px, `--space-6`=24px.

### Border Radius
| Token | Value |
|---|---|
| `radius-sm` | 4px |
| `radius-md` | 6px |
| `radius-lg` | 8px |
| `radius-xl` | 12px |

### Icons
**Always Lucide — no other icon library, no emoji as icons.**

### Shell Layout
```
┌─────────────────────────────────────────┐
│  TOPBAR (full width, 52px, sticky)      │
│  [ ☰ ] [ logo ] ··· [ theme toggle ]   │
├──────────┬──────────────────────────────┤
│ SIDEBAR  │  MAIN CONTENT               │
│ 220px    │  padding: var(--space-6)    │
└──────────┴──────────────────────────────┘
```
- Topbar always full width — spans over sidebar
- Sidebar starts at `top: 52px`, `height: calc(100vh - 52px)`
- Logo lives in topbar, never in sidebar
- Sidebar collapses to 56px via `layout--collapsed`
- `bordered=False` by default

### Critical Rules
- **Token-first, always** — never hardcode values in components; all design values must be CSS custom properties
- **Lucide icons exclusively** — no alternatives permitted
- All CSS is generated by `css_gen.py` — zero file copying

### Pages & Routing
```python
# Static route
@app.page("/", title="Dashboard")
def dashboard():
    bq.title("Dashboard")

# Dynamic route — {param} extracted at runtime via window.__burqParams
@app.page("/contacts/{contact_id}", title="Contact Detail")
def contact_detail(contact_id):
    bq.contact_profile(endpoint="/contacts/{contact_id}")
```
**FastAPI catch-all route must be placed AFTER all API routes** — otherwise it intercepts API calls.

## 9. FastAPI Integration

```python
from fastapi import FastAPI, Request
from fastapi.staticfiles import StaticFiles
from fastapi.templating import Jinja2Templates

server = FastAPI()
server.mount("/static", StaticFiles(directory="dist/static"), name="static")
templates = Jinja2Templates(directory="dist/templates")

# All API routes must be prefixed /api to avoid conflict with burq page routes
@server.get("/api/contacts")
def get_contacts(): ...

# Catch-all MUST be last — placing it earlier intercepts API calls
@server.get("/{full_path:path}")
def catch_all(request: Request, full_path: str):
    template_name = full_path.replace("/", "_") or "index"
    return templates.TemplateResponse(request, f"{template_name}.html", {})
```

## 13. Working Style & Conventions

- **Token-first always** — no hardcoded values anywhere in component output
- **Lucide only** — never emoji, never other icon libs
- **File preference**: complete final files > partial diffs; EXCEPT `html_gen.py` (large) → use targeted `str_replace`-style blocks with clear insertion markers
- **Environment**: Windows Command Prompt (not PowerShell); use `type nul >` to create empty files
- **All API routes prefixed `/api`** to avoid catch-all conflicts
- **CSS is 100% generated** — never copy static CSS files
- **Burq never generates route files** — FastAPI owns routing
- **Error reporting**: shows file, line number, ±2 lines of context, skips burq internals — points directly at user code
- **Charts accept**: static Python list, pandas DataFrame, or `bq.fetch()` descriptor
