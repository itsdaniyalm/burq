App
Entry point — defines your application, theme, and navigation.
class bq.App(title, api_base, theme=None, layout=None, logo="default", author=None) ▶
Root application object. All pages must be registered on an App instance via @app.page().
ParamTypeDefaultDescription
title*str—App name, used in topbar and <title>
api_base*str—Base URL for all bq.fetch() calls
themeThemeNoneTheme config — see Theme below
layoutLayoutNoneShell layout config
logostr | None"default""default" = burq SVG mark, None = no logo, SVG string, or file path
authorstrNoneAuthor name in generated meta tags
example
import burq as bq

app = bq.App(
    title="My CRM",
    api_base="http://localhost:8000/api",
    theme=bq.Theme(mode="dark", toggle=True),
    logo="default",
)
class bq.Layout(sidebar=True, topbar=True, bordered=False, show_title=False) ▶
Shell layout configuration. bordered=False is the clean default. show_title shows the app title text next to the logo in the topbar.
ParamTypeDefaultDescription
sidebarboolTrueShow/hide sidebar nav
topbarboolTrueShow/hide topbar
borderedboolFalseRender chrome borders (topbar bottom, sidebar right)
show_titleboolFalseShow app title text beside logo in topbar
method app.nav(items: list[NavItem]) ▶
Set the sidebar navigation items. Call once before defining pages.
example
app.nav([
    bq.NavItem("Dashboard", icon="layout-dashboard", href="/"),
    bq.NavItem("Contacts",  icon="users",            href="/contacts"),
    bq.NavItem("Settings",  icon="settings",         href="/settings"),
])

Theme
Compiles to CSS custom properties. Every token overridable.
class bq.Theme(mode="dark", toggle=True, font_sans="Space Grotesk", font_mono="Space Mono", radius="md", ...overrides) ▶
Full theme config. Defaults to the Filament theme (#F08C1A accent). Any semantic token can be overridden via keyword args.
ParamTypeDefaultDescription
modestr"dark""light" or "dark" — initial mode
toggleboolTrueShow theme toggle button in topbar
font_sansstr"Space Grotesk"Body/UI font — any Google Font
font_monostr"Space Mono"Code/CLI font — any Google Font
font_size_baseint14Base font size in px
radiusstr"md""none" "sm" "md" "lg" "xl" "2xl"
border_widthint1Border width in px
shadow_strengthstr"md""none" "sm" "md" "lg"
spacing_unitint4Base spacing unit in px
dark_accentstr"#F08C1A"Override dark mode accent color
light_accentstr"#F08C1A"Override light mode accent color
dark_backgroundstr"#0a0a0b"Override dark page background
light_backgroundstr"#fef9ed"Override light page background
Note: All light_* and dark_* token params follow the same pattern. See README for the full override table.
custom brand example
bq.Theme(
    mode="dark",
    toggle=True,
    dark_accent="#6366f1",       # indigo
    dark_background="#0f0e17",
    light_accent="#4f46e5",
    radius="lg",
)
📄
@app.page
Register a Python function as a compiled page.
decorator @app.page(path: str) ▶
Registers a function as a page. Each page compiles to one Jinja2 template in dist/templates/. Dynamic route params like {id} are extracted via inline JS into window.__burqParams.
static route
@app.page("/")
def dashboard():
    bq.title("Dashboard")
    bq.metric("Users", "2,480")
dynamic route
@app.page("/contacts/{contact_id}")
def contact_detail(contact_id):
    bq.contact_profile(endpoint="/contacts/{contact_id}")
    # {contact_id} is replaced at runtime from window.__burqParams

Layout Components
Context managers for building page structure.
context bq.row()  |  bq.col() ▶
bq.row() — horizontal flex container. bq.col() — vertical flex container.
with bq.row():
    bq.metric("Total", "100")
    bq.metric("Active", "84")
context bq.grid(cols: int)  /  bq.span(cols: int) ▶
CSS grid layout. Use bq.span() inside bq.grid() to control column span of each child.
with bq.grid(cols=4):
    with bq.span(cols=1):
        bq.metric("Practices", "48")
    with bq.span(cols=2):
        bq.metric("Revenue", "$2.4M")
    with bq.span(cols=1):
        bq.metric("Risk", "12")
context bq.card(title=None) ▶
Card container with optional header title. Renders on the surface background.
with bq.card("Workspace Settings"):
    bq.input("Name", icon="building-2")
    bq.button("Save", variant="primary")
context bq.box(background="muted", border=False, radius="md", padding="md", foreground=None) ▶
Styled container with explicit background, border, radius, and padding control.
ParamTypeDefaultDescription
backgroundstr"muted""muted" "surface" "accent" or any CSS color
borderboolFalseRender border using theme border color
radiusstr"md"Border radius token
paddingstr"md""sm" "md" "lg"
with bq.box(background="muted", border=True, radius="lg"):
    bq.text("Custom styled container", muted=True)
context bq.tabs(labels: list[str])  /  bq.tab(label: str) ▶
Tab container. bq.tabs() declares the tab bar labels, bq.tab() defines each panel's content. Labels must match exactly.
with bq.tabs(["Overview", "Details", "History"]):
    with bq.tab("Overview"):
        bq.metric("Total", "42")
    with bq.tab("Details"):
        bq.text("Detail content here")
    with bq.tab("History"):
        bq.table(data=bq.fetch("GET", "/history/"), columns=["date", "action"])
fn bq.divider()  |  bq.spacer(size="md") ▶
bq.divider() — horizontal rule. bq.spacer() — vertical whitespace. Size: "sm" "md" "lg" "xl"

Display
Text, headings, and visual display components.
fn bq.title(text)  |  bq.heading(text)  |  bq.text(text, muted=False) ▶
Text hierarchy. title = 24px page heading. heading = 16px section heading. text = 14px body with optional muted style.
bq.title("Dashboard")
bq.heading("Recent Activity")
bq.text("Showing last 30 days.", muted=True)
fn bq.metric(label, value, trend=None, trend_dir=None, icon=None, variant="default") ▶
KPI metric card with optional trend indicator and icon.
ParamTypeDefaultDescription
label*str—Metric label
value*str—Main display value
trendstrNoneTrend value e.g. "+12%"
trend_dirstrNone"up" or "down" — controls color
iconstrNoneLucide icon name
variantstr"default""default" "accent" "danger" "success"
bq.metric("Revenue", "$84k", trend="+12%", trend_dir="up", icon="trending-up")
bq.metric("Churn", "3.2%", trend="-0.4%", trend_dir="down", variant="danger")
fn bq.badge(text, variant="default") ▶
Inline status badge.
defaultinfosuccesswarningdangeraccent 
bq.badge("Active", variant="success")
bq.badge("Critical", variant="danger")
fn bq.avatar(initials, size="md") ▶
Avatar circle with initials. Size: "sm" "md" "lg".
bq.avatar("DM", size="lg")
fn bq.progress(label, value: int, variant="default") ▶
Progress bar. value is 0–100.
bq.progress("Completion", 72, variant="success")
fn bq.markdown(content)  |  bq.spinner()  |  bq.skeleton(variant="text") ▶
bq.markdown() renders via marked.js CDN. bq.spinner() loading spinner. bq.skeleton() loading placeholder — variant: "text" "card" "avatar".
fn bq.code_block(content, language="python", filename=None) ▶
Read-only syntax-highlighted code block with line numbers. Renders via Prism.js at runtime. Supported languages: python, javascript, bash, json, html.
ParamTypeDefaultDescription
content*str—Source code string to display
languagestr"python"Syntax language for highlighting
filenamestrNoneOptional filename shown in header bar

app.py python 
import burq as bq
from burq.compiler import compile_app

app = bq.App(
    title="My CRM",
    api_base="http://localhost:8000/api",
    theme=bq.Theme(mode="dark", toggle=True),
)

@app.page("/")
def dashboard():
    bq.title("Dashboard")
    bq.metric("Users", "2,480", trend="+12%", trend_dir="up")

compile_app(app, output_dir="dist")
fn bq.rich_text(name, label=None, placeholder=None, endpoint=None, value=None) ▶
WYSIWYG rich text editor that serializes to Markdown on submit. Toolbar includes headings, bold, italic, strikethrough, links, bullet/ordered lists, blockquote, inline code, and code block. The markdown value is submitted as a hidden <input> field using name. Use endpoint for auto-save on blur via POST to your API.
ParamTypeDefaultDescription
name*str—Form field name — submitted as markdown string
labelstrNoneLabel shown above editor
placeholderstrNonePlaceholder shown in empty editor
endpointstrNoneAPI endpoint for auto-save on blur e.g. "/notes/{id}"
valuestrNonePre-fill with existing markdown content

Data
Table hydration, fetch descriptors, and column config.
fn bq.table(data, columns, column_config={}, searchable=False, sortable=False, checkable=False, row_href=None) ▶
Full-featured data table. Hydrated at runtime via JS from your API. Supports client-side search, pagination (10/page), CSV export, and row click navigation.
ParamTypeDefaultDescription
data*fetch()—Data source — must be a bq.fetch() descriptor
columns*list[str]—Column keys to display, in order
column_configdict{}Key → ColumnConfig for custom rendering
searchableboolFalseClient-side search across all visible columns
sortableboolFalseClick-to-sort column headers
checkableboolFalseRow selection checkboxes
row_hrefstrNoneRow click URL — use {id} for dynamic IDs e.g. "/items/{id}"
fn bq.fetch(method, endpoint, data=None) ▶
Compile-time fetch descriptor. At runtime, burq.js calls api_base + endpoint. Dynamic params like {id} are interpolated from window.__burqParams.
class Column Config Types ▶
Column renderers passed to column_config in bq.table().
ClassParamsDescription
AvatarColumninitials_key, sub_keyAvatar circle with initials + sub-label below name
BadgeColumnvariant_map: dictBadge colored by value e.g. {"active": "success"}
CurrencyColumnprefix="$", decimals=2Formatted number with prefix and decimals
DateColumn—Human-readable date format
BoolColumntrue_label, false_labelBoolean rendered as success/default badge
TextColumnmuted=FalsePlain text cell, optional muted style

Feedback
Alerts, modals, accordions, pagination, and empty states.
fn bq.alert(message, type="info") ▶
Inline alert banner. Type: "info" "success" "warning" "error"
context bq.modal(id, title, size="md")  /  bq.modal_body()  /  bq.modal_footer() ▶
Modal dialog with body and footer sections. Size: "sm" "md" "lg" "xl"
fn bq.accordion(items: list[dict], multiple=False) ▶
Collapsible accordion. Each item: {"title": str, "content": str, "open": bool}. multiple=True allows multiple panels open at once.
fn bq.pagination(total, page, per_page=10, on_change=None) ▶
Pagination controls. on_change is a JS function name called with the new page number. Note: tables include built-in pagination — this is for manual use.
fn bq.empty_state(title, message, icon=None, action=None) ▶
Empty state placeholder. Tables render this automatically when data is empty or search returns zero results.
⚙️
API Helpers
Runtime JS bridges, contact profile, and NavItem.
fn bq.open_modal(id)  |  bq.close_modal(id) ▶
Generates inline onclick JS for ModalManager.open(id) / ModalManager.close(id). Use with bq.button().
fn bq.contact_profile(endpoint: str) ▶
Self-hydrating profile header for detail pages. Fetches name, email, avatar, and status from your API at runtime. Endpoint supports {param} interpolation.
class bq.NavItem(label, icon: str, href: str) ▶
Sidebar navigation item. icon must be a valid Lucide icon name. Active state is automatically applied based on URL match.
Icons: Always Lucide — see lucide.dev/icons for names.

CLI
Command-line interface for creating, building, and watching.
cmd burq new <project-name> ▶
Scaffold a new burq project.
Creates:
cmd burq build ▶
Compile app.py → dist/. Shows per-file output and total build time.
cmd burq dev ▶
Watch app.py, pages/, components/ — recompile on every .py save. Debounces 300ms. Skips dist/ and __pycache__.
fn compile_app(app, output_dir="dist") ▶
Programmatic entry point for the compiler. Typically called at the bottom of app.py. Called automatically by burq build and burq dev.
