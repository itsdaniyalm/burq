Build a UI in Python.
No JavaScript required.
burq is a Python UI compiler. You write Python components, burq compiles them to pure Vanilla JS + HTML + CSS. This tutorial walks you through building your first app from scratch.
~20 min Python 3.10+ FastAPI backend no JS needed
1
Install burq
One pip install — no Node, no Webpack, no build tools.
burq is a pure Python package. Install it into your project's virtual environment:
terminal
pip install burq
Verify it installed correctly:
terminal
burq --help
⚡ burq — Python UI compiler

Commands:
  new Scaffold a new burq project
  build Build for production → dist/
  dev Watch for changes and recompile
Tip: Always install burq inside a virtual environment — python -m venv venv then pip install burq.
2
Create a project
Scaffold the project structure with one command.
Run burq new with your project name. This creates a ready-to-go folder structure:
terminal
burq new my-app
cd my-app
The scaffold looks like this:
project structure
my-app/
├── app.py          # your entire UI lives here
├── pages/          # optional: split pages into separate files
├── components/     # optional: custom reusable components
├── dist/           # compiled output — never edit manually
└── .gitignore      # dist/ is gitignored by default
Note: The dist/ folder is generated by burq. Never edit it manually — always edit app.py and recompile.
3
App config
Configure your app, theme, and layout in app.py.
Open app.py. Everything starts with a bq.App instance. This is the root of your application — it holds your theme, layout, navigation, and pages.
app.py
import burq as bq
from burq.compiler import compile_app

app = bq.App(
    title="My CRM",                          # shown in browser tab
    api_base="http://localhost:8000/api",    # base URL for all data fetches
    theme=bq.Theme(
        mode="dark",      # "light" or "dark"
        toggle=True,      # show theme toggle button in topbar
        font_sans="Space Grotesk",
        font_mono="Space Mono",
        radius="md",
    ),
    layout=bq.Layout(
        sidebar=True,     # show sidebar nav
        topbar=True,      # show topbar
        bordered=False,   # clean borderless chrome
    ),
    logo="default",       # burq logo — or pass a file path / SVG string
)
Theme compiles to CSS custom properties — every color, radius, font, and spacing value is a token. You can override any of them:
custom brand colors
theme=bq.Theme(
    mode="dark",
    dark_accent="#6366f1",         # indigo accent
    dark_background="#0f0e17",
    light_accent="#4f46e5",
    chart_colors=["#6366f1", "#f472b6", "#2ec97a"],
)
Tip: api_base is the URL prefix for all bq.fetch() calls. If your FastAPI runs on port 8000 with an /api prefix, set it to "http://localhost:8000/api".
4
Navigation
Define your sidebar nav with NavItem and NavGroup.
Call app.nav() once before defining your pages. Each NavItem takes a label, a Lucide icon name, and an href.
flat navigation
app.nav([
    bq.NavItem("Dashboard", icon="layout-dashboard", href="/"),
    bq.NavItem("Contacts",  icon="users",            href="/contacts"),
    bq.NavItem("Deals",     icon="circle-dollar-sign", href="/deals"),
], footer=[
    bq.NavItem("Settings",  icon="settings",         href="/settings"),
])
For grouped sub-pages, use NavGroup. It renders a collapsible section with a chevron. It auto-opens when the current URL matches any child href:
grouped navigation
app.nav([
    bq.NavItem("Dashboard", icon="layout-dashboard", href="/"),
    bq.NavGroup("Contacts", icon="users", children=[
        bq.NavItem("All Contacts", href="/contacts"),
        bq.NavItem("Import",       href="/contacts/import"),
    ]),
    bq.NavItem("Deals", icon="circle-dollar-sign", href="/deals"),
], footer=[
    bq.NavItem("Settings", icon="settings", href="/settings"),
])
Icons: Always use Lucide icon names — find them at lucide.dev/icons. Never use emoji as icons.
5
Your first page
Register a page function and add components.
Decorate a function with @app.page(path) to register it as a page. Inside the function, call burq components imperatively — like Streamlit, but the output is compiled to static HTML.
app.py
@app.page("/")
def dashboard():
    bq.title("Dashboard")
    bq.text("Welcome back. Here's what's happening.", muted=True)
    bq.spacer()

    # metric cards in a 4-column grid
    with bq.grid(cols=4):
        with bq.span(cols=1):
            bq.metric("Contacts", "2,480", trend="+12%", trend_dir="up", icon="users")
        with bq.span(cols=1):
            bq.metric("Deals",    "143",   trend="-4%",  trend_dir="down", icon="circle-dollar-sign")
        with bq.span(cols=1):
            bq.metric("Revenue",  "$84k",  trend="+8%",  trend_dir="up", icon="trending-up")
        with bq.span(cols=1):
            bq.metric("Churn",    "3.2%",  variant="danger", icon="alert-triangle")

    bq.spacer()

    # card with content inside
    with bq.card("Recent Activity"):
        bq.text("No activity yet.", muted=True)
Dynamic routes work the same way — add {param} to the path and accept it as a function argument. burq extracts it from the URL at runtime via JS:
dynamic route
@app.page("/contacts/{contact_id}")
def contact_detail(contact_id):
    bq.contact_profile(endpoint="/contacts/{contact_id}")
    bq.spacer()
    bq.title("Contact Detail")
Tip: The {contact_id} placeholder in bq.contact_profile(endpoint=...) is replaced at runtime with the actual URL value — you don't handle this manually.
6
Fetching data
Connect your table to a live API endpoint.
bq.fetch() is a compile-time descriptor. At build time it records the method and endpoint. At runtime, burq.js calls api_base + endpoint, gets the JSON response, and hydrates the table automatically.
app.py
@app.page("/contacts")
def contacts():
    bq.title("Contacts")

    bq.table(
        data=bq.fetch("GET", "/contacts/"),
        columns=["name", "company", "status", "created_at"],
        column_config={
            "name":       bq.AvatarColumn(sub_key="email"),
            "status":     bq.BadgeColumn(variant_map={
                "lead":      "default",
                "qualified": "info",
                "won":       "success",
                "lost":      "danger",
            }),
            "created_at": bq.DateColumn(),
        },
        searchable=True,
        sortable=True,
        row_href="/contacts/{id}",   # click row → navigate to detail page
    )
Your FastAPI endpoint should return a JSON array:
fastapi endpoint (your backend)
@app.get("/api/contacts/")
def get_contacts(db: Session = Depends(get_db)):
    contacts = db.query(Contact).all()
    return [
        {
            "id":         c.id,
            "name":       c.name,
            "email":      c.email,
            "company":    c.company,
            "status":     c.status,
            "created_at": c.created_at.isoformat(),
        }
        for c in contacts
    ]
Note: burq never touches your backend. It only generates a fetch() call in the compiled JS. Your FastAPI owns all routing and data — burq just consumes the JSON.
7
Charts
Add bar, line, area, and donut charts with one function call.
Charts accept either static Python data or a bq.fetch() descriptor — same pattern as tables. Colors are pulled automatically from your theme's chart_colors.
static data (great for testing)
@app.page("/")
def dashboard():
    bq.title("Dashboard")

    with bq.grid(cols=2):
        with bq.span(cols=1):
            bq.bar_chart(
                data=[
                    {"month": "Jan", "revenue": 4000},
                    {"month": "Feb", "revenue": 3200},
                    {"month": "Mar", "revenue": 5100},
                    {"month": "Apr", "revenue": 4700},
                ],
                x="month",
                y="revenue",
                title="Monthly Revenue",
                height=260,
            )
        with bq.span(cols=1):
            bq.donut_chart(
                data=[
                    {"status": "Won",    "count": 42},
                    {"status": "Active", "count": 31},
                    {"status": "Lost",   "count": 18},
                ],
                label="status",
                value="count",
                title="Deal Breakdown",
                height=260,
            )
live data from API
bq.line_chart(
    data=bq.fetch("GET", "/stats/trends"),
    x="date",
    y=["signups", "churns"],    # multiple lines
    title="Growth Trends",
    smooth=True,
    height=300,
)
grouped bars
bq.bar_chart(
    data=bq.fetch("GET", "/stats/revenue"),
    x="month",
    y=["revenue", "expenses"],  # grouped
    title="Revenue vs Expenses",
    stacked=False,
)
Tip: Use a pandas DataFrame directly — data=df. burq serializes it to JSON at compile time. No bq.fetch() needed for data you already have in Python.
8
Forms
Inputs, selects, toggles, and buttons.
Form components use the same imperative pattern. Group them inside a bq.card() for the standard settings layout.
settings page example
@app.page("/settings")
def settings():
    bq.title("Settings")

    with bq.tabs(["General", "Notifications", "Danger Zone"]):

        with bq.tab("General"):
            with bq.card("Workspace"):
                bq.input("Workspace Name", icon="building-2")
                bq.input("API Base URL",   icon="link", placeholder="https://")
                bq.select("Timezone", options=["UTC", "America/New_York", "Asia/Karachi"])
                bq.button("Save Changes", variant="primary", icon="save")

        with bq.tab("Notifications"):
            with bq.card("Email Notifications"):
                bq.toggle("New assignment",  checked=True)
                bq.toggle("Weekly digest",   checked=False)
                bq.toggle("Risk alerts",     checked=True)
                bq.divider()
                bq.button("Save", variant="primary", icon="save")

        with bq.tab("Danger Zone"):
            bq.alert("These actions cannot be undone.", type="warning")
            bq.spacer()
            with bq.card("Delete Workspace"):
                bq.text("Permanently delete this workspace and all data.", muted=True)
                bq.button("Delete Workspace", variant="danger", icon="trash-2")
Use bq.modal() for confirmation dialogs:
modal example
bq.button("Delete", variant="danger", onclick=bq.open_modal("confirm-delete"))

with bq.modal("confirm-delete", "Confirm Delete"):
    with bq.modal_body():
        bq.text("This action cannot be undone.", muted=True)
    with bq.modal_footer():
        bq.button("Cancel", onclick=bq.close_modal("confirm-delete"))
        bq.button("Delete", variant="danger", icon="trash-2")

Build & serve
Compile your app and wire it to FastAPI.
At the bottom of app.py, call compile_app(). Then run burq build from your terminal:
app.py — bottom of file
compile_app(app, output_dir="dist")
terminal
burq build
✓ base.html
✓ templates/index.html
✓ templates/contacts.html
✓ templates/settings.html
✓ tokens.css, layout.css, components.css, burq.js

⚡ Burq build complete → dist/ [38ms]
Now wire your FastAPI to serve the compiled output:
fastapi backend (main.py)
from fastapi import FastAPI, Request
from fastapi.staticfiles import StaticFiles
from fastapi.templating import Jinja2Templates

app = FastAPI()
app.mount("/static", StaticFiles(directory="dist/static"), name="static")
templates = Jinja2Templates(directory="dist/templates")

# ── page routes — one per burq page ──
@app.get("/")
def index(request: Request):
    return templates.TemplateResponse(request, "index.html", {"page_title": "Dashboard"})

@app.get("/contacts")
def contacts(request: Request):
    return templates.TemplateResponse(request, "contacts.html", {"page_title": "Contacts"})

@app.get("/contacts/{contact_id}")
def contact_detail(request: Request, contact_id: int):
    return templates.TemplateResponse(request, "contacts_contact_id.html", {"page_title": "Contact"})

Note: burq never generates FastAPI route files. Your backend owns all routing. burq compiles templates only — FastAPI serves them. This is an intentional boundary.
10
Dev mode
Watch for changes and recompile automatically.
Instead of running burq build after every change, run burq dev. It watches app.py, pages/, and components/ — and recompiles within 300ms of any save.
terminal — two windows
# window 1 — your FastAPI server
uvicorn main:app --reload

# window 2 — burq watcher
burq dev

Tip: FastAPI's --reload flag restarts the server when your backend changes. burq dev restarts compilation when your UI changes. Run both together for a smooth dev loop.
